# Player photos

Upload one photo per player into this folder, then add its credit to `credits.csv`.

- **File name:** the player's name in lowercase with hyphens, for example `bukayo-saka.jpg`. The Photos page on the site (About → Photo checklist) shows the exact file name for every player.
- **Formats:** .jpg, .jpeg, .png or .webp. Keep each file under about 600 KB (the 640px download size on Wikimedia Commons is ideal).
- **Credits:** each photo needs one row in `credits.csv`: `file,photographer,licence,source`. Example row:
  `bukayo-saka.jpg,Jane Doe,CC BY-SA 4.0,https://commons.wikimedia.org/wiki/File:Example.jpg`
- A photo only appears on the site once its credit row is filled in. Players without a photo keep their shirt card.

Only upload photos whose licence allows reuse (for example Creative Commons licences on Wikimedia Commons), and credit them as the licence asks.
